## Situation
Gotchas — portée `ia-locale`. Entrée d'origine datée du 2026-07-16.

## Rule
Ollama : `/api/chat` (rôles) pour le dialogue, `/api/generate` (complétion) pour le single-shot.

## Evidence
Multi-tours via `/api/generate` en concaténant l'historique dans un prompt fait **dériver** le modèle (il « complète » de faux tours `Utilisateur:/Assistant:`, recrache le cadre système). `/api/chat` (`messages:[{role:'system'|'user'|'assistant', content}]`) sépare proprement les rôles → pas de dérive, système explicite. Même streaming NDJSON que `generate` mais le fragment est dans `message.content` (pas `response`). Garder `generate()` pour résumer/reformuler (usages sans conversation). `chat()`/`generate()` dans src/lib/ollama.ts
