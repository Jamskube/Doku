## Situation
Gotchas — portée `ia-locale`. Entrée d'origine datée du 2026-07-24.

## Rule
RAG local (ADR-0015) : appariement de fichiers-couple garanti par checksum, jamais par coïncidence de taille.

## Evidence
Un index vectoriel = 2 fichiers (vectors.bin Float32 + meta.json avec les textes). Chacun écrit atomiquement (tmp+rename) NE garantit PAS l'appariement du couple : un crash entre les deux renames laisse un bin neuf + un vieux meta de MÊME nombre de lignes ≠ mêmes lignes → vecteurs silencieusement désappariés, indétectable (les hashes par fichier matchent, ça ne s'auto-répare jamais). Correctif : stocker le SHA-1 du bin DANS meta.json, le revérifier au chargement, mismatch → jeter et ré-indexer (un index est un cache, jeter est toujours sûr). Écrire bin d'abord, meta ensuite (meta décrit un bin qui existe déjà). Incrémental = seul le travail d'EMBED est incrémental (diff par hash de contenu) ; la persistance réécrit tout le couple (2,9 Mo/1000 notes, trivial — pas de comptabilité d'offsets).
