## Situation
Ajouter une animation d'ouverture (menu, popover, pastille, rideau) qu'une touche peut déclencher.

## Rule
Aucune animation sur une action clavier : poser `.kbd` (animation: none) à l'OUVERTURE si `event.detail === 0` ou chemin clavier ; ne jamais retirer `.kbd` d'un élément affiché. Rideau : classe `.snap` puis double rAF.

## Evidence
2026-10-20 : la relecture review-animations a bloqué la pastille de mode, le menu « / », le badge de zoom et le rideau Ctrl+Maj+E, animés au clavier.
