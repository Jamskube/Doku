## Situation
Gotchas — portée `securite`. Entrée d'origine datée du 2026-07-13.

## Rule
DOMPurify conserve les `<img src>` RELATIFS — (`pic.png`) mais **strippe les chemins ABSOLUS** (`G:\…`, non-URL).

## Evidence
Pour un export HTML **portable** (ouvert hors iframe/CSP), inliner les images en `data:` **AVANT** `sanitizeHtml` (pré-résolution + base64) — ne jamais compter sur la sanitize pour préserver un chemin local. Corollaire : une image bloquée (réseau/UNC) laissée telle quelle n'est arrêtée que par la CSP → la neutraliser **à la source** (retourner `null` → image supprimée), comme `live-preview::imageSrc`
