## Situation
Gotchas — portée `ui`. Entrée d'origine datée du 2026-07-17.

## Rule
Ne jamais utiliser le token de texte `--ink-rgb` pour les ombres d’élévation.

## Evidence
En thème sombre, `--ink-rgb` devient presque blanc : toute ombre diffuse (`box-shadow: … rgba(var(--ink-rgb), …)`) se transforme en glow clair. Utiliser un token indépendant (`--shadow-rgb`) — sombre/noir dans les deux thèmes — et, si nécessaire, un filet net séparé pour les surfaces élevées.
