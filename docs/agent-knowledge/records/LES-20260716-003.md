## Situation
Gotchas — portée `svelte`. Entrée d'origine datée du 2026-07-16.

## Rule
Svelte 5 `$state` profond : muter via l'INDEX du tableau, pas la ref locale poussée.

## Evidence
Pousser un objet plain dans un `$state([])` array le proxifie ; la variable locale qui référence l'objet pointe le **raw**, pas le proxy → `local.content += t` ne re-render PAS. Muter via l'index (`copilot.messages[idx].content += t`) passe par le proxy → réactif. Capturer l'index juste après le push (`const idx = arr.length - 1`) et l'utiliser dans le callback de streaming
