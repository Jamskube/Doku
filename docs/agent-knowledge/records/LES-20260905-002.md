## Situation
Le contrôle visuel des documents générés (ADR-0029) capturait le rendu avec `html2canvas` pour l'envoyer au critique OpenAI.

## Rule
Pour juger un rendu, capturer avec le moteur qui rend : sérialiser le document en XHTML (`XMLSerializer`), le poser dans un `<foreignObject>` SVG chargé en `data:` dans une `Image`, dessiner sur un canvas. Chromium/WebView2 rend fidèlement, n'exécute aucun script, ne charge aucune ressource externe, et `toDataURL` n'est pas souillé. `html2canvas` réimplémente le CSS et se trompe (grid, polices) : le critique aurait corrigé des artefacts de la bibliothèque, pas du document.

## Evidence
Vérifié dans Chromium via Playwright le 2026-09-05 sur une page témoin (texte, grid, tableau, SVG inline, image `data:`, badge) : JPEG de 42 Ko, pixels de chaque zone présents, `xmlns` XHTML ajouté automatiquement par le sérialiseur. Dépendance `html2canvas` retirée (commit c5b69e4). Limite : polices Web externes absentes (pas de réseau), fond du canvas à remplir soi-même sous la hauteur du document.
