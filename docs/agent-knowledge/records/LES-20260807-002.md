## Rule
Drag-to-scroll horizontal sans casser le clic des enfants

## Evidence
(fil d'Ariane, barres à scrollbar masquée) : (1) seuil de ~4 px avant de basculer en drag — en deçà c'est un clic normal ; (2) `setPointerCapture` au moment où le drag commence (fluidité + événements hors élément) ; (3) le `click` parasite généré en fin de drag s'avale via un handler **en phase capture** sur le conteneur (`onclickcapture` → preventDefault+stopPropagation si drag) ; (4) reset du flag en `setTimeout(0)` dans pointerup — sinon un relâchement hors bouton laisse le flag armé et avale le clic légitime suivant ; (5) tactile = natif via `touch-action: pan-x` (ne gérer que `pointerType === 'mouse'` en JS) ; (6) affordance = fondus `mask-image` togglés sur scroll.
