## Rule
`minimalSetup` (paquet `codemirror`) embarque `defaultKeymap` — dont **`Mod-/` → `toggleComment`**.

## Evidence
Si un raccourci applicatif utilise Ctrl+/ (bascule source), l'éditeur focus **commente la ligne** en plus → perte de données. Neutraliser via `Prec.highest(keymap.of([{ key: 'Mod-/', run: () => true }]))`. **Tester les gestes destructifs avec l'éditeur focus** (une vérif sans focus ne déclenche pas le keymap CM et masque le bug). [2026-08-10, 2ᵉ morsure] Le champ de mines est plus large : **`Mod-i` → `selectParentSyntax`**, **`Shift-Mod-k` → `deleteLine`**… — invisibles au grep du projet (c'est dans node_modules).
