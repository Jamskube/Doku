## Situation
Workarounds — portée `editor`. Entrée d'origine datée du 2026-07-10.

## Rule
Pousser un contenu externe dans un éditeur CM6 **caché-par-onglet** (cache d'`EditorState` par onglet) sans remount :

## Evidence
ajouter un compteur `rev` sur l'onglet, le lire dans le `$effect` Svelte, et `setState(makeState(...))` quand `rev` change (invalider aussi le cache des onglets inactifs rechargés). Le `$effect` ne re-render que sur changement d'id d'onglet — `rev` est le hook minimal pour le forcer sur un reload disque
