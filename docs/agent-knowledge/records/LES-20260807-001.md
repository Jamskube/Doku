## Situation
Gotchas — portée `verification`. Entrée d'origine datée du 2026-08-07.

## Rule
Vérif Playwright d'une UI Svelte : ne jamais lire le DOM dans le MÊME tick qu'un `click()` déclenché en JS

## Evidence
— le re-rendu Svelte est asynchrone (microtask), la lecture voit l'ancien DOM (vécu : enfants d'arbre « absents » juste après le clic de dépliage). Relire dans une évaluation séparée ou un `setTimeout` ; pareil pour toute assertion post-interaction.
