## Situation
Commentaires d'un PDF exporté par Doku (ou annoté dans Acrobat) rouverts dans le lecteur de Doku, qui ne rend que le canvas.

## Rule
Le rendu canvas de pdf.js ne peint pas un pense-bête `/Text` sans apparence `/AP` : il appartient à la couche d'annotations, jamais montée ici. Les lire par `page.getAnnotations()` (`pdfFileComments`) et les épingler soi-même.

## Evidence
2026-09-17 : « je vois les cadres, surlignages, mais pas les commentaires » ; test pdf.js en boucle fermée `rend un commentaire que le lecteur de Doku relit (pdf.js)`.
