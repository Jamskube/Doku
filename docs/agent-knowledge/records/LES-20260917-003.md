## Situation
Tester « Ouvrir Doku au démarrage » dans une copie isolée (identifiant `…mwtest`) sur la machine du mainteneur. Rayon : son entrée de démarrage Windows réelle.

## Rule
Le plugin autostart nomme la valeur `Run` d'après le `productName` (« Doku »), pas l'identifiant : une copie isolée écrit la VRAIE entrée. Relever la valeur avant tout essai, la restaurer après.

## Evidence
2026-09-17 : le test a supprimé puis réécrit l'entrée que le mainteneur venait d'activer (pointant vers son exe de dev) ; restaurée à l'identique via `Set-ItemProperty`.
