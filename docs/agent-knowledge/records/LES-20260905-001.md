## Situation
Doku est sous AGPL-3.0 et versionne `public/bgraph.wasm`, compilé depuis un fork local dont le source est gitignoré (`add-ons/`, confidentiel par la licence bgraph). L'auteur de bgraph a donné une autorisation orale, élargie le 2026-09-05 à « absolument ce qu'on veut ».

## Rule
Un binaire distribué dans un dépôt AGPL doit être accompagné de son source correspondant : un `.wasm` dont le source est gitignoré viole la licence de Doku lui-même, quelle que soit la permission de l'auteur du blob. La permission lève l'obstacle ; seule la publication du source du fork (patch inclus) ferme le point.

## Evidence
Revue du 2026-09-05 (angle critique, confirmé sur `LICENSE` et `package.json` `"license": "AGPL-3.0-or-later"`). ADR-0028 amendée : autorisation élargie consignée, geste restant nommé — versionner le fork (`vendor/bgraph/` + patch + note d'autorisation) et faire échouer `npm run build:bgraph` sans le patch. Décision de publier laissée au mainteneur : c'est irréversible.
