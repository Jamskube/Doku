# docs

## Purpose
Documentation du projet Doku : planification produit, décisions d'architecture, design, sprints, journal de bord.

## Files
| Folder | Purpose |
|---|---|
| `planning/` | Artefacts produit : brainstorm, PRD (v1/v1.5/v2), spec UX, architectures, epics |
| `adr/` | Décisions d'architecture (une par fichier, index dans son README — 16 ADR) |
| `design/` | Maquettes et D.A. : w1 (fenêtre principale), w2-copilot, w3-rephrase-popover, installer-nsis |
| `sprints/` | Fichiers de sprint, rétros, et `ledger.json` (vérité de complétion) |
| `journal/` | Journal par session (`YYYY-MM-DD.md`) + pointeur de reprise `_next-session.md` |
| `archives/` | Documents obsolètes conservés pour référence (vide actuellement) |
