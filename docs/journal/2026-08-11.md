## Discoveries
- **`contain: layout paint` = bloc conteneur ET boîte de clip pour toute surface flottante** — vécu 3× le même jour : un pop absolu dans le composer est clippé par les overflow, un fixed est déplacé par le transform du flip des faces. Recette : rendre les surfaces flottantes à la RACINE de l'élément `contain` et calculer les coordonnées dans son repère (aperçu citation, menu verbosité).
- **Le graphe de modules Vite permet d'injecter l'état réel dans les vérifs navigateur** : `await import('/src/lib/copilot.svelte.ts')` depuis la console = la MÊME instance de module que l'app → pousser messages/modèles/statuts et exercer les vrais handlers Svelte (aperçu de citations vérifié sans natif ni RAG).
- **L'événement scroll arrive une frame APRÈS le mouseover** (inertie trackpad, scrollIntoView) : un dismiss-on-scroll qui clear le timer d'ouverture rend un aperçu au survol quasi inatteignable — ne fermer que ce qui est déjà ouvert, laisser vivre le timer (il relit une position fraîche à l'affichage).
- **Un drop-guard (« if (checking) return ») fait mentir les awaiters** : `resolveRuntime` await le refresh — recevoir l'état périmé affiche « Connectez votre clé » avec une clé valide. Coalescer (partager la promesse en vol, motif `readyPromise`), jamais abandonner. Attrapé par le code-reviewer.
- **Deux consignes de prompt jumelles produisent deux sorties jumelles** : « court paragraphe ou puces » vs « puces courtes » → deux listes identiques. Contraster les LIVRABLES (prose interdite de puces vs 5-10 puces factuelles).
- Un panneau `inert` rend `focus()` silencieusement no-op (l'action « Poser une question » ne faisait littéralement rien quand le composer était sur la face Contexte).
- **Le piège HMR de l'injection d'état** : une fois le module ÉDITÉ dans la session, l'app tourne sur `…copilot.svelte.ts?t=<timestamp>` ; importer l'URL nue rend une SECONDE instance (state muté, DOM inchangé, zéro erreur — plusieurs allers-retours perdus). `location.reload()` ne suffit pas. Recette : lire l'URL réellement chargée via `performance.getEntriesByType('resource')` et importer celle-là. Mémoire AGENTS.md corrigée en conséquence.
- **Une constante de découpe calibrée pour le LOCAL appliquée au cloud coûte N appels au lieu d'un** : le chat avait reçu son budget cloud (240k), pas le résumé — d'où les minutes d'attente sur un PDF de 5 pages, mises à tort sur le compte de l'indexation locale.
- **Vérifier une animation en figeant le temps** : `getAnimations()` + `currentTime` + attente de DEUX rAF donne des positions mesurables ; la variante `animation-delay` négatif + lecture immédiate renvoie l'état de la frame PRÉCÉDENTE (mesures décalées d'un cran, diagnostic faux).

## Decisions
- « Poser une question » supprimée des actions rapides (le composer est juste dessous) → remplacée par « Lister les actions à faire » (mode `todos`, porte de sortie honnête « aucune action »).
- Citations des résumés : single-fenêtre seulement — les numéros d'extraits ne survivraient pas aux passes map-reduce (assumé, commenté dans le code).
- Style des réponses : « équilibré » = no-op strict (comportement historique) ; consigne jamais appliquée aux passes intermédiaires du map-reduce.
- Mono réservée aux tags techniques locaux (`qwen2.5:…-q4_0`) ; les noms de modèles cloud sont des noms de produits → Inter.
- UI épurée : bords remplacés par des fonds pleins ; gardés = outlines focus (a11y), pastilles d'état, séparateurs, tableaux Markdown (contenu).
- Le texte du raisonnement cloud reste IGNORÉ (aucun monologue interne affiché) — seul le fait qu'il commence est signalé.
- Attente = points + libellé shimmer SANS en-tête ; l'en-tête « Doku-San » marque l'arrivée du texte (deux états visuellement distincts, pas de redondance).
- Icônes : le subset Material Symbols reste la règle ; exception assumée pour « nouvelle conversation » (SVG Lucide inline au trait, style repris de `KX_Agent`).
