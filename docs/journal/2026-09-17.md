## Discoveries

- `core:default` n'inclut pas `window.show` : un `show()` sous try/catch masque le refus derrière le filet de 4 s. → LES-20260917-002
- Un `listen()` global Tauri reçoit aussi les événements `emit_to` visant une autre fenêtre (`EventTarget::Any`). (non retenu)
- Une révision qui reçoit le brief de création redessine le bloc ; `<change>` sur extrait exact garde le balisage. → LES-20260917-001
- Plugin autostart : valeur `Run` nommée d'après `productName`, une copie isolée écrit la vraie entrée du mainteneur. → LES-20260917-003
- Relancer un flux LLM seulement tant qu'aucun delta ni outil n'est parti : au-delà, la réponse serait dupliquée. (non retenu — cap atteint)
- Test d'une copie isolée pendant le `tauri dev` du mainteneur : identifiant, `CARGO_TARGET_DIR`, port Vite et port CDP distincts. → inbox `/visual-check`
- Un bouton `disabled` ne reçoit aucun événement de survol (Chromium). (non retenu)
- `calc(var(--doc-width) * var(--doc-zoom))` avec `none` devient invalide et retombe sur `max-width: none` — le comportement voulu en pleine largeur. (non retenu)
- `frameLocator().evaluate` dans une iframe sandboxée journalise des « Blocked script execution » : artefact du test, pas de l'app. (non retenu)
- Copie isolée en debug avec Vite redémarré : ~40 s avant l'exécution de `main.ts` ; une sonde à 7 s donnait un faux négatif. (non retenu)
- pdf.js ne peint pas un `/Text` sans `/AP` sur le canvas : commentaires à lire par `getAnnotations()`. → LES-20260917-004
- Onglet HTML en aperçu : éditeur masqué, iframe `sandbox=""` opaque ; révéler dans l'iframe `allow-same-origin` par le texte rendu. → LES-20260917-005
- `setPointerCapture` posé au `pointerdown` vole le clic (cible = ancêtre commun) : capture au début du glisser. → source ajoutée à LES-20260807-002
- Heredoc du Bash tool : un antislash doublé devant `n` est effondré en simple, la chaîne JS embarquée reçoit un vrai saut de ligne et casse. → source ajoutée à user:LES-20260827-004
- Geste qui lit le curseur OS : CDP ne le bouge pas (SendInput DPI-aware) ; piloter la souris pendant que le mainteneur teste a produit un faux « détachement ». → inbox `/visual-check`
- pdfjs-dist 6 : `convertToViewportRectangle` et `PDFDocumentProxy.destroy` absents (`convertToViewportPoint`, `loadingTask.destroy`). (non retenu)
- `openTab` dédoublonne par chemin : une reprise d'onglet sans garde perdrait le contenu déplacé. (non retenu)
- `build:installer:arm64` depuis Git Bash : GNU tar ne lit pas le zip Ollama (déjà écrit dans le script) ; lancer depuis PowerShell. (non retenu)
- `core:window:default` n'autorise ni `set_position` ni `set_size` : un test CDP ne peut pas déplacer la fenêtre. (non retenu)

## Decisions

- La session d'onglets n'appartient qu'à la fenêtre `main` ; les fenêtres `doku-N` démarrent vides et passent par l'invite à la fermeture.
- Un onglet détaché ne quitte sa fenêtre qu'à l'accusé de réception de la nouvelle (jeton `doku://tab-moved`).
- Repères de bloc recalculés depuis le HTML assaini, jamais stockés : aperçu et prompt partagent la numérotation, exports propres.
- Pas de fenêtre préchargée cachée : la permission `allow-show` suffit à rendre l'ouverture immédiate.
- Mode veille = présence de l'icône de la zone de notification (lue au moment de fermer) ; lancé avec `--autostart` et veille active, la fenêtre reste masquée.
- « Réfléchir » : OpenAI `effort: high`, MiniMax M3 sans `thinking: disabled` ; M2.x réfléchit toujours (bouton grisé expliqué). Appels internes toujours bridés.
- Commentaires d'un PDF : lecture seule dans Doku (hors carnet), épingle dans la gouttière droite, bulle sous l'épingle.
- Glisser d'onglet : la fenêtre d'origine garde la capture et pilote ; le curseur et la barre visée sont lus côté Rust (px physiques) ; la fenêtre glissée part hors écran au-dessus d'une barre (masquer risquerait la capture) ; seul onglet d'une fenêtre secondaire = la fenêtre elle-même ; la principale arrache toujours.
- Pas de fenêtre préparée d'avance : un aperçu dessiné dans la fenêtre d'origine couvre le délai d'apparition ; onglet entrant sans pointillés (retour mainteneur).
