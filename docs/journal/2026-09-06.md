# 2026-09-06 — Disque réparé, composeur refondu, palette « / », version 3.5.0

## Summary

Journée en quatre temps. **Le disque** : le T7 (volume `G:`) était marqué non intègre et `node_modules\.vite` corrompu ; `chkdsk G: /f` en administrateur a réparé, `node_modules` reconstruit, Vite redémarre. **Deux corrections demandées** : les marqueurs `[n]` du chat n'apparaissent plus dans les documents générés, et la modale d'un document se centre. **Le composeur refondu** sur une maquette validée en localhost (variante E) : le « + » ouvre un seul menu à trois sections dépliables, la jauge de verbosité y est déplacée à l'identique, les jetons « Créer » et « Bref » disparaissent. **Une palette de commandes « / »** avec autocomplétion flottante, douze commandes. Version 3.5.0, deux installateurs Windows produits. Aucun commit.

## Fixed

- **`node_modules\.vite` illisible** : entrée NTFS corrompue, pas un bug Vite.
- **Modale document en haut à gauche** : le reset `* { margin: 0 }` écrasait le `margin: auto` du navigateur ; seule modale de l'app sans le rétablir.
- **Port 1420 occupé** après mon test : `timeout npm run dev` tue npm, pas le node enfant.

## Discoveries

- **`chkdsk /scan` est impossible sur un disque USB** (pas d'instantané VSS) ; `/f` hors connexion en admin, tout fermé. Trois `found.00x` datés du 2 septembre : deuxième corruption en quatre jours, 0 secteur défectueux → lien USB, pas la flash. *(non retenu — cas isolé)*
- **Git Bash résout `tar` vers GNU tar 1.35**, qui ne lit pas un ZIP ; celui de Windows (bsdtar) le fait. Un build lancé depuis Bash échoue sur « This does not look like a tar archive ». *(non retenu — voir 09-11)*
- **Deux « + » côte à côte qui ne veulent pas dire la même chose** (ajouter au contexte / créer un livrable) : c'était la vraie gêne, pas le nombre de boutons. *(journal)*
- **Une commande qui bascule (`/web`) prend un sens différent avec une suite** : « /web météo » doit activer, pas basculer. *(corrigé le 09-11)*

## Decisions

- **Variante E** : trois sections, une seule ouverte, valeur courante en sous-titre. La jauge reste la jauge.
- **La liste d'autocomplétion flotte au-dessus du champ**, ancrée à la carte de saisie, devant le bandeau Contexte.
- **Les commandes qui ouvrent un dialogue ne se déclenchent qu'à la validation** ; les autres acceptent une suite.
- **Installateurs 3.5.0 produits sans commit** : `41d5ed6c…` (ARM64, 24,3 Mo), `9b91d229…` (x64, 28,6 Mo), non signés.
