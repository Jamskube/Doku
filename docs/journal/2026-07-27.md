## Discoveries
- L'installateur NSIS par défaut de Tauri est **en anglais** et brut — jamais regardé en 15 sprints : la D.A. s'arrêtait au bord de la fenêtre de l'app.
- `bundle.windows.nsis.template` permet de remplacer le template entier → fonds/textes/désinstalleur habillables (`MUI_BGCOLOR`, `SetCtlColors`, `MUI_INSTFILESPAGE_COLORS`, `BrandingText` avec échappements `${U+XXXX}`). Limite dure : boutons/checkbox/progressbar restent Win32 natifs.
- Playwright MCP : `file://` bloqué (servir en localhost) ; screenshots seulement sous `G:\Doku\.playwright-mcp`.
- PowerShell 5.1, deux pièges d'encodage la même session : `Get-Content`/`-replace`/`Set-Content` mojibake les accents (lecture ANSI) — `Cargo.toml` corrompu puis restauré via git ; `Out-File -Encoding utf8` met un BOM qui atterrit dans le titre du commit (`-F`). Parade : outil Edit/node + `WriteAllText(UTF8 sans BOM)`.
