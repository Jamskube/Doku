# Journal — 2026-08-12

## Summary
Doku dispose maintenant d'un installateur Windows x64 reproductible, testé localement et sur GitHub Actions. La régression de l'animation des points pendant le streaming a également été corrigée. Vérifications exécutées : `npm run check`, `npm test`, `npm run build`, `npm run build:installer:x64`, contrôle PE x64, génération Qwen réelle et smoke test d'installation NSIS.

## Added
- `/.github/workflows/build-windows-x64.yml` — construit, installe, smoke-teste et publie automatiquement l'installateur NSIS x64.
- `/scripts/prepare-ollama-sidecar.mjs` — prépare les sidecars Ollama CPU ARM64 ou x64 depuis les archives officielles épinglées.
- `/src-tauri/resources/` — embarque la licence Ollama et documente les ressources distribuées.
- `/DESIGN.md` et `/.impeccable/design.json` — formalisent le système visuel extrait de l'interface Doku.
- `/.impeccable/critique/2026-08-11T11-09-17Z__src-components-copilotpanel-svelte.md` — conserve l'audit indépendant du panneau copilote.

## Modified
- `/package.json` — ajoute les commandes de préparation Ollama et de compilation des installateurs ARM64/x64.
- `/AGENTS.md` et `/README.md` — documentent le support Windows ARM64/x64 et les nouvelles commandes.
- `/src-tauri/binaries/README.md` — décrit le flux multiarchitecture et les contrôles de cohérence.
- `/src-tauri/tauri.conf.json` — embarque les licences dans l'application installée.
- `/src/components/CopilotPanel.svelte` — finalise le polish Impeccable, les interactions accessibles et le sélecteur de modèle attaché.

## Fixed
- `/src/components/CopilotPanel.svelte` — préserve le mouvement des points pendant le streaming après minification CSS.
- `/.github/workflows/build-windows-x64.yml` — smoke-teste l'installation dans le chemin NSIS réel sous `%LOCALAPPDATA%\Doku`.

## Discoveries
- Le payload Ollama x64 CPU charge `llama-server.exe` et génère réellement avec Qwen sous Windows x64.
- L'installateur NSIS Tauri courant installe silencieusement dans `%LOCALAPPDATA%\Doku` ; le dossier `/D=` attendu n'était pas utilisé par le smoke test initial.

## Decisions
- Le paquet x64 embarque uniquement le moteur Ollama CPU nécessaire afin de garder l'installateur à environ 20 Mo.
- Le build x64 est reproductible par commande locale et par workflow GitHub manuel ou déclenché sur tag `v*`.
