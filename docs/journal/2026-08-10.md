## Discoveries (2ᵉ partie)
- **CM6 réutilise le DOM d'un widget remplacé** (`updateDOM` sur instance non-eq) : le DOM ET ses listeners restent ceux de l'ANCIEN widget. Géométrie changée ⇒ `return false` (rebuild), et toute position lue dans un listener doit venir de `posAtDOM` au moment du geste, jamais d'un champ figé à la création.
- **Le defaultKeymap de CM6 a mordu une 2ᵉ fois** : `Mod-i` = `selectParentSyntax` (invisible au grep — c'est dans node_modules). Avant de lier un raccourci : vérifier `@codemirror/commands/dist/index.js`, et `Prec.highest`. (`Shift-Mod-k` = deleteLine, miné aussi.)
- **Hôte contenteditable vide + enfant non éditable = frappe muette** (Chromium ne pose pas de caret exploitable, même placé à la main dans un nœud texte vide) : séparer strictement zone de saisie et chrome (span interne éditable).
- **Les API compatibles OpenAI peuvent mentir en HTTP 200** : MiniMax met ses erreurs dans `base_resp.status_code` (1004 = clé invalide) avec un statut 200 — ne JAMAIS valider une clé sur le statut HTTP seul.
- **PowerShell corrompt l'UTF-8 sans BOM** : `Get-Content -Raw` (décodage ANSI) + `Set-Content -Encoding utf8` = mojibake sur tous les accents. Jamais de passe regex PowerShell sur des sources — outil Edit uniquement (openai.rs restauré depuis git).
- Le sous-agent critic sur PLAN puis le code-reviewer sur DIFF attrapent des classes d'erreurs différentes : 3 Critical évités avant code (20.4) + le HTTP-200-menteur après (MiniMax) — le cycle complet a payé trois fois aujourd'hui.

## Discoveries (1ʳᵉ partie)
- Le subset local (hb-subset) de Material Symbols casse les ligatures de certains noms (`search`, `keep`, `check`… — substitutions en chaîne avec glyphes intermédiaires) : sans fermeture GSUB elles sont élaguées, avec fermeture les 3 600 glyphes reviennent (356 Ko). Le subsetter officiel Google (`css2?icon_names=`) est la voie fiable — documenté dans `scripts/subset-icons.mjs`.
- Fenêtre Playwright occluse : rAF et transitions gelés (~1 fps) — échantillonner en boucles rAF DANS une seule évaluation ; des animations mises en pause via `getAnimations()` persistent et bloquent les transitions suivantes de l'élément.
- Une propriété CSS personnalisée héritée animée sur `:root` invalide le style de tout le document et repeint le fond plein écran à chaque frame (reflet du chrome) — seuiller les écritures et bannir la transition.
- Open Notebook (étude) : ne jamais faire recopier des IDs opaques à un LLM — numéroter côté app, le modèle ne recopie qu'un chiffre ; leur clic ouvre une modale, Doku va plus loin (passage exact surligné).

## Decisions
- Citations ancrées : validation déterministe côté app (numéro hors liste → retiré ; refus honnête → pas de sources) ; petit document = document complet découpé en extraits numérotés (aucun embedding, marche aussi en cloud) ; pied « Passages cités » filtré aux extraits réellement cités dans ce mode.
- PDF : précision à la page + surlignage des rectangles d'items — jamais de faux surlignage (passage introuvable → halo de page ; scanné → ouverture simple).
- Provenance d'une note sauvée : capturée à la fin de la génération (`sourceLabel`), jamais résolue au clic ; sans certitude → pas de « d'après ».
- Budgets de contexte par fournisseur : 12k local (index éphémère au-delà) / 240k cloud (troncature signalée au-delà) — badge et comportement sur le même seuil.
- Non retenu d'Open Notebook : flux « Ask » multi-requêtes (latence ×N et décomposition douteuse sur 1.5b), podcast/STT, notebooks/API (le système de fichiers joue ce rôle). Retenu pour plus tard : transformations personnalisées, contrôle du contexte (→ /sprint plan).

## Decisions (2ᵉ partie)
- MiniMax : carte préréglée, architecture générique dessous (choix utilisateur) ; liste de modèles dynamique avec repli catalogue ; défaut `MiniMax-M2.5`. Base URL en dur dans le binaire : une clé volée ne peut pas être redirigée.
- La clé API n'est acceptable QUE si c'est la seule voie d'auth du fournisseur (ADR-0018) — pour OpenAI, la règle « jamais de clé » demeure.
- Ctrl+B volontairement muet dans une cellule de tableau (îlots 20.2 stopPropagation) — no-op assumé et documenté au ledger.
- Insertions de blocs APRÈS la sélection, jamais à sa place (le texte sélectionné est le chemin d'accès au menu, pas une cible à effacer).
