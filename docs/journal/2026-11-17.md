# 2026-11-17

## Summary
Nouvel outil **Signature** dans le lecteur PDF : la signature manuscrite est tracée une fois (doigt, stylet ou souris), conservée sur l'appareil, puis posée sur n'importe quelle page. Elle se redimensionne et se tourne par poignées, l'épaisseur se choisit dans le pavé, et l'export « PDF avec les annotations » la grave dans une copie. Commit `3f15dc1`, poussé. Installateur ARM64 3.6.1 recompilé (17:52).

## Discoveries
- Les fractions de page 0..1 ne sont pas isotropes : angles, distances et tailles par défaut se calculent en unités de hauteur de page (`x * pageAspect`).
- Ajouter un cran SOUS le minimum : trois planchers en aval — affichage `strokePixels` (était 1,6 px), relecture du carnet (1), gravure (0,5 pt). Le plancher d'affichage aurait rendu « Très fin » identique à « Fin » sous 800 px de page. (Application de LES-20260820-001.)
- `fs:allow-remove` ne couvre pas la racine de `$APPDATA` : « oublier » vide le fichier au lieu de le supprimer.
- Le pavé doit être rendu HORS du `div.pdf-shell`, sinon Échap ferme le pavé ET épluche une couche du lecteur (`ownsGlobalKeys`).
- `trash-2` n'est pas dans le jeu d'icônes connu du sprite ; utiliser `trash`.
- Collision de nom : `drawingFrame` existait déjà (numéro de frame `requestAnimationFrame`) ; la fonction de cadre s'appelle `selectionFrame`.
- Écrire du code contenant des backticks dans un `node -e "…"` ou un heredoc non quoté via Git Bash les fait exécuter (LES-20260827-004 rejoué deux fois) : passer par un script `.mjs` écrit avec Write.
- `trail check` signale par recouvrement de mots : 15 conflits sur ce commit, 15 faux positifs après lecture de chacun. (non retenu)
- `tauri dev` s'est arrêté (exit 1) pendant `build:installer:arm64` après un rechargement Vite sur un asset de codegen de la build release ; cause non vérifiée. (non retenu)
- Le harnais `.agent/visual/pdf-annotations/harness.html` monte le vrai `PdfView` en navigateur : itérations d'environ 1 min contre plusieurs minutes de compilation Tauri. → LES-20261117-001

## Decisions
- Signature = un tracé `ink` ordinaire du carnet : déplacement, gomme, annulation, impression et gravure viennent gratuitement, sans changement de manifeste.
- Pas de signature numérique (certificat) : le PDF porte le dessin d'une signature, rien qui prouve qui l'a posée.
- Rotation et redimensionnement transforment les points ; aucune orientation n'est stockée.
- Une signature enregistrée avant le réglage d'épaisseur se relit en trait fin (2).
