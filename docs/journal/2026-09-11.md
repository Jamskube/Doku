## Discoveries

- **Un nettoyage textuel de ponctuation appliqué à une chaîne HTML réécrit le CSS et le SVG.** Le remède est structurel : opérer sur les nœuds texte d'un DOM parsé, jamais sur la sérialisation. → record machine.
- **Un `<dialog>` perd son centrage sous un reset universel `* { margin: 0 }`** : le navigateur le centre par `margin: auto`, que le reset écrase ; il faut le rétablir explicitement, plus `max-width/max-height: none` contre les bornes de l'agent utilisateur. → record machine.
- **Reconfigurer un `Compartment` CM6 ne rebâtit pas un `ViewPlugin`** qui ne surveille que `docChanged/selectionSet/viewportChanged` : comparer la facette entre `startState` et `state`. → record projet.
- **Retirer un blob AVANT de tronquer** : coupé au milieu, le blob n'est plus reconnaissable et passe entier. → record projet.
- **Changer un découpeur sans incrémenter la version de l'index persisté** laisse les anciens chunks en place, le hash de fichier ne bougeant pas. → record projet.
- **Deux relecteurs à contextes séparés qui convergent** sur cinq points sans se parler : signal plus fort que dix tours séquentiels ; chaque point a été vérifié à la source avant correction. *(déjà porté par la règle du swarm — journal)*
- **Des installateurs produits sans commit ne correspondent à rien** : 3.5.0 et 3.5.1 sont deux binaires sans hash, `Cargo.lock` modifié hors commit. Un rapport « en 3.5.1 » est inattribuable. *(journal — c'est au mainteneur de commiter et tagger)*
- **Git Bash place GNU `tar` devant celui de Windows** : un script npm qui extrait un ZIP par `tar` échoue depuis Bash et passe depuis PowerShell. *(non retenu, cap)*

## Decisions

### Discoveries

- **Ne jamais sauter une invite de sauvegarde sur la foi d'une écriture dont l'échec est avalé** : `localStorage.setItem` lève `QuotaExceededError` (~10 Mio/origine, 5 dès un caractère non-Latin-1) ; le `catch` muet fait restaurer l'AVANT-DERNIÈRE session — plausible et faux. La fonction de persistance rend `boolean`, l'invite s'y conditionne. → record machine.
- **Un `$effect` Svelte 5 qui focalise et sélectionne un champ en lisant le brouillon lié re-tourne à chaque frappe** et écrase la saisie ; ne dépendre que du drapeau d'ouverture (ou `untrack`). → record machine.
- **Quand la session gagne un nouvel occupant de volet (note sans chemin), tout prédicat « volet occupé » dérivé du chemin devient faux sans changer** — `split`, `activePaneId`, `unsaved`. Inventorier ces prédicats à chaque nouvel occupant. → record projet.
- `app.tabs.push(raw)` puis écriture sur `raw` : invisible après la première lecture réactive (la source est initialisée paresseusement) — rendre `app.tabs.at(-1)`. *(journal — corrigé, un seul site)*
- Sérialiser des index puis filtrer à la lecture décale les index : garder des trous `null`. *(journal)*
- Un item de menu qui n'existe que dans un mode où la surface ouvrant le menu n'est pas rendue est une branche morte : compter les surfaces, pas les modes. *(journal)*
- Playwright : `page.locator('.tab').first().click({ button: 'right' })` + `import('/src/lib/stores.svelte.ts')` via le graphe Vite suffit pour vérifier menu, session et volets sans natif. *(déjà LES-20260811-005)*

### Decisions

- **« Renommer l'onglet » ne renomme QUE l'onglet** (étiquette `label`, persistée par chemin) ; le champ ne montre jamais l'extension ; vide = retour au nom de fichier. Renommer un fichier reste le geste de l'explorateur. Décision du mainteneur à l'essai.
- Une note sans chemin ≤ 500 k caractères n'est plus demandée au quit ; fermer son onglet le demande encore.
- Un document généré intact revient sans point (« pristine ») ; une note en cours revient avec.
- Non retenu : couleur d'onglet, fractionner, exporter, rechercher depuis le menu d'onglet.
