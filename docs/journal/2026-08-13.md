## Discoveries

- Une échelle PDF calculée uniquement au montage laisse un backing store obsolète après les transitions de largeur ; il faut redimensionner immédiatement le layout, puis différer le rerendu HiDPI jusqu’à la stabilisation.
- Une classe responsive de direction doit être conditionnée par l’état fonctionnel `split` : la largeur seule ne prouve pas qu’un second volet existe.
- Un menu de volet scalable doit vivre dans la top layer, choisir son sens d’ouverture et séparer la liste scrollable de ses actions persistantes.

## Decisions

- Le bureau conserve un buffer unique par document ; un même onglet ne peut pas être affiché simultanément dans les deux volets.
- En fenêtre étroite, les deux vrais volets s’empilent ; sans split, le document unique occupe toujours toute la hauteur.
- Les annotations PDF visées restent non destructives et sont stockées hors du PDF dans AppData.
- Le vrai Mica Windows 11 reste réservé au thème sombre ; le thème clair conserve le matériau CSS opaque.
