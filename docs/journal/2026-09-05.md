## Fixed

- **Un clic dans l'aperçu agrandi pouvait envoyer un beacon** : `<svg><a href="https://…">` passait le hook d'ancres (`tagName === 'A'` est faux en SVG).
- **Le critique visuel aurait jugé html2canvas, pas Chromium.**
- **L'aperçu PDF validait une colonne de 714 px, l'impression en donnait 593.**
- **Un document de 100 Ko laissait la bulle vide plusieurs minutes.**
- **Un bump de version des discussions aurait rendu les anciennes invisibles.**

## Discoveries

- **`String.replace(pattern, chaîne)` interprète `$'` dans la chaîne de remplacement** et colle tout le reste du fichier : un script d'édition qui injecte du code doit passer une fonction. Trois heures de scripts précédents ont survécu par chance. → record machine.
- **Un dépôt AGPL qui distribue un `.wasm` sans son source viole sa propre licence**, quelle que soit la permission de l'auteur du blob. → record projet.
- **Capturer avec le moteur qui rend** : XHTML dans un `foreignObject` SVG, image `data:`, canvas — fidèle, sans script, sans réseau. → record projet.
- **La revue technique comptait 30 `catch {}` vides ; le code en a 1.** Les autres sont des `catch { // raison }` documentés. Un chiffre d'agent se vérifie avant d'agir dessus. *(non retenu — LES-20260831-002 le dit déjà)*
- **`Test-Path` dit faux, `dir` dit vrai** : un volume NTFS marqué dirty produit des entrées listables mais inaccessibles. `Get-Volume` → « Spot Fix Needed ». *(non retenu — cas isolé)*

## Decisions

- **Contrat de sortie = HTML brut dans `<doku-document title="…">`**, JSON accepté en repli.
- **Retirer plutôt que geler** : la correction PDF masquée, les scrapers. Git garde tout.
- **Rust assumé (ADR-0030)**, **répartition local/cloud assumée (ADR-0031)**.
- **Corbeille, jamais suppression définitive**, pour les notes.
- **Publier le source du fork bgraph : décision du mainteneur**, pas de l'agent — c'est irréversible.
- **Signature et updater : plan écrit, activation quand les secrets existeront.**
- **Tags/frontmatter et annotations PDF → RAG : reportés**, la recommandation du swarm disait « rien de neuf tant que 1 à 5 ne sont pas faits ».
