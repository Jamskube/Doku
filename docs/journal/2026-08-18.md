## Fixed
- **Le copilote cloud sous Linux** — `write_secret` y rendait « disponible sous Windows », donc ni OpenAI ni MiniMax. Aucune garde par plateforme dans le frontend : le seul verrou était ces trois souches Rust.
- **MiniMax lent** — trois appels au modèle par tour (extraction mémoire du tour précédent, sélection des souvenirs, question réelle), tous à profondeur de raisonnement **par défaut**, pendant qu'OpenAI était bridé à l'effort `low` sur chacun des siens. L'asymétrie était dans Doku, pas chez les fournisseurs.
- **Trois cadrages qui visaient le contenant au lieu de la chose cherchée** : la citation du chat amenait le haut de la **page** PDF alors que le passage peut être n'importe où dessus ; le plan du document utilisait `scrollIntoView: true` (= `y: 'nearest'`, le défilement minimal, donc le titre collé au bord) ; la liste d'annotations centrait la page, pas le tracé.
- **Le menu de sélection tronqué par le bas** — « Réécrire avec Doku-San » hors d'atteinte. Le plafond existait ; c'est `menuHeight` qui valait 230 au lieu de 268, parce que le menu est retiré du DOM à chaque fermeture et n'est donc **jamais** mesurable à l'ouverture. Seconde passe après montage, borne basse ajoutée, filet CSS.
- **Une clé MiniMax valide était refusée** — `compat_set_key` interrogeait d'abord `GET /models`, point d'entrée que le code documente lui-même comme **facultatif**, et son échec de *transport* abandonnait tout, alors que la sonde autoritaire attendait juste en dessous. Le repli existait pour le 404, pas pour la coupure de connexion : deux façons pour un point d'entrée absent de se manifester, une seule traitée.
- **Les annotations PDF ne se sauvegardaient pas sous Linux** — le motif `**` du périmètre `fs` ne matche pas un chemin absolu Linux (pas d'alignement sur le `/` initial, pas de traversée d'un composant caché), or `appDataDir()` y vaut `~/.local/share/…`. **Toute** écriture de Doku dans ses propres données était refusée : annotations, instantanés, index RAG, mémoire du copilote. Invisible sous Windows.
- **L'AppImage plantait au démarrage sur Arch** (`EGL_BAD_PARAMETER`) — elle embarque le GTK et le Mesa du runner Ubuntu via `linuxdeploy-plugin-gtk`. Aucun réglage `WEBKIT_*` n'y change rien : le message vient de **GDK**, donc sous WebKit.
- **L'interface annonçait un coffre Windows** à un utilisateur Linux, sur quatre libellés en dur — un texte faux vaut une fonctionnalité muette.
- **La sélection de zone ne fonctionnait pas du tout** — son calque de capture était posé **dans** `.pdf-actions`, donc dimensionné sur la barre d'outils : quelques pixels en haut à droite.

## Discoveries
- **`reasoning_split` ne coupe rien.** Le paramètre a tout l'air d'un frein — il ne fait que router la pensée hors du contenu. Le modèle réfléchit autant ; on ne le voit simplement plus, ce qui rend l'attente **muette** au lieu de la raccourcir. Confirmé sur la doc MiniMax.
- **`thinking: {"type":"disabled"}` n'agit que sur M3** ; les M2.x l'ignorent, réflexion incluse. Le défaut de Doku est resté `MiniMax-M2.5` — un nouvel utilisateur atterrit donc sur le modèle que le correctif ne peut pas accélérer.
- **Les configs par plateforme de Tauri 2 suivent RFC 7396** : une clé à `null` est *supprimée*. C'est ce qui a permis de retirer le sidecar côté Linux sans toucher au fichier de base, donc sans remettre en jeu des installateurs qui marchent.
- **Un jeton OAuth sans portée `workflow` ne peut pas pousser un fichier de workflow** — le push est refusé sur ce seul fichier, tout le reste étant prêt. `gh auth refresh -s workflow` règle la cause ; pousser en SSH la contourne, ce qui aurait laissé le blocage revenir au commit suivant.
- **`keyring` 4 installe le magasin de la plateforme paresseusement au premier `Entry::new`** (feature `v1`, `LazyLock`), et sur \*nix c'est le Secret Service en `zbus` — du Rust pur. Vérifié **dans le code source de la caisse** : sans ça, on livrait du code qui compile et casse à l'exécution sur « aucun magasin par défaut ».
- **L'API des releases GitHub expose un `digest` sha256 par asset.** Épingler l'empreinte d'une archive de 1,44 Go ne demande pas de la télécharger — et les empreintes Windows déjà épinglées dans le script correspondent au bit près, ce qui valide la source.
- **`prepare-ollama-sidecar.mjs` exige le `tar.exe` de Windows** (bsdtar) : lancé depuis Git Bash, dont le GNU tar ne lit pas les zip, il échoue sur « Not found in archive ». Le piège est écrit dans le script — je suis tombé dedans quand même, parce que le `&&` derrière un pipe masquait le code de sortie.
- **Un `catch {}` muet coûte un aller-retour complet.** Deux fois aujourd'hui : sur le réseau (`map_err(|_| …)` × 5) et sur l'écriture des annotations. Le message était honnête sur le **fait** et muet sur la **raison** — ce qui ne vaut guère mieux que le silence.
- **Le mécanisme `endOfContent` de pdf.js ne se transplante pas ici** : chez eux la couche texte est seule dans son cadre, chez nous elle est prise entre le surlignage et le dessin. Mesuré aux deux modes (aperçu du surligneur disparu, sélection de lecture bloquée), puis retiré entièrement.
- **pdf.js expose `getSignatures()`** — signataire, date, motif, sans aucune cryptographie. Je l'avais déclaré impossible en regardant au mauvais endroit du typage.
- **`makepkg` refuse de tourner en root**, par conception : un utilisateur dédié est nécessaire dans un conteneur CI.
- **Arrêter une tâche qui pilote `npm` ne tue pas le processus lancé.** Un serveur de dev orphelin a bloqué le port 1420 de l'utilisateur pendant des heures.

## Decisions
- **v3.0.0.** L'application avait énormément bougé depuis 2.2.0 ; un installateur avait même été renommé `2.4.0` à la main.
- **La réflexion de MiniMax est coupée pour la conversation aussi**, pas seulement pour les appels internes — c'est ce qui rend M3 vif, et c'est aligné sur le bridage d'OpenAI à l'effort `low`. On y perd de la profondeur sur les questions difficiles ; c'est un `"disabled"` à passer en `"adaptive"` si l'arbitrage change.
- **`thinking` n'est envoyé qu'aux M3.** La doc dit que les M2.x l'ignorent, mais « ignoré d'après la doc » ne vaut pas « accepté par le service » : ne l'envoyer qu'aux modèles où il agit fait passer le risque de faible à nul.
- **Linux = AppImage + Ollama du système** (ADR-0025). Empaqueter 1,44 Go pour dupliquer ce qu'un `pacman -S ollama` fait mieux, et met à jour tout seul, n'a aucun sens. Le sidecar Windows n'existe que parce que Windows n'a pas de gestionnaire de paquets sur lequel compter.
- **Windows n'est PAS migré sur `keyring`** (ADR-0026). La convention de nommage des identifiants y diffère : basculer orphelinerait **en silence** les secrets déjà stockés — compte OpenAI déconnecté, clé MiniMax disparue, sans message ni cause visible. Une seconde implémentation coûte moins cher.
- **README en anglais, le reste de `docs/` en français.** Le dépôt est public et les visiteurs lisent l'anglais ; la documentation de travail reste écrite pour ceux qui construisent.
- **Paquet Arch compilé DANS Arch**, ni `.deb` repackagé ni AppImage. Le raisonnement retenu pour Ollama — ne pas transporter ce que la distribution fournit mieux — vaut pour **toute** la pile système, pas seulement pour le sidecar. Je ne l'avais appliqué qu'à moitié.
- **Trois emprunts à Okular retenus** : signature (détecter et le dire, jamais juger), présentation, sélection de zone. Écarté : les marges rognées. Non poursuivis : formulaires AcroForm et vérification cryptographique — quelqu'un les fait déjà bien, gratuitement.
- **Pas de bouton pour le mode présentation** : `F5` suffit, un guide des raccourcis viendra.
- **La sélection de zone est un mode exclusif** : tout clic ailleurs l'éteint. Un mode qu'on garde sans le vouloir change le sens de tous les clics suivants.

## Verified
- **Au navigateur, pas seulement au raisonnement** : le menu de sélection mesuré dans un vrai Chrome. Fenêtre 1280×760 → menu à 480→748 pour une hauteur réelle de 268, soit exactement `760 − 268 − 12` : la passe correctrice a bien mesuré. Fenêtre 1100×380 → 100→368, entièrement dedans.
- **La branche Linux compilée avant d'être livrée** : `cfg` inversés temporairement pour `sidecar.rs`, puis banc de recoupement dédié compilant le code de production **à l'identique** pour `x86_64-unknown-linux-gnu` (`keyring` n'étant pas dans le graphe sous Windows, l'inversion ne suffisait plus).
- **CI Linux verte du premier coup** — 8 min 5, `Doku_3.0.0_amd64.AppImage` (87 Mo), empreinte vérifiée en local après téléchargement.
- Les 47 liens internes des fichiers de documentation touchés sont vérifiés par script. Trois étaient morts dans la première version du README : des noms de fichiers ADR devinés au lieu d'être lus.
- **Le paquet Arch installé POUR DE VRAI en CI** (`pacman -U`), puis `ldd` sur le binaire installé : trois liaisons résolues vers `webkit`, `gtk-3` et `soup`, aucun « not found ». C'est exactement le contrôle qui manquait à l'AppImage — laquelle avait passé tous les miens en étant inutilisable. Un contrôle qui ne peut pas échouer ne vérifie rien.
- **Le `.deb` inspecté à la main** depuis Windows : 14 Mo contre 87, aucune bibliothèque graphique dans la charge utile, `Depends: libwebkit2gtk-4.1-0, libgtk-3-0` — déclarées, pas portées.
- **Doku tourne sur Arch**, confirmé par l'utilisateur : première sortie de Windows depuis le début du projet.

## Échecs assumés
- **Le mécanisme `endOfContent`** livré sans pouvoir être observé, qui a cassé deux fonctions qui marchaient (aperçu du surligneur, sélection de lecture). Annulé le jour même, diagnostic consigné dans `feasibility-selection-pdf-et-okular.md`. « Copié fidèlement depuis l'amont » n'est pas une vérification.
- **La sélection de lecture reste imparfaite.** Le recadrage au pointeur améliore le cas du dépassement de marge, mais le fond — le navigateur qui étend aux bords de ligne — n'est pas résolu. La voie Okular (calculer la sélection sur la géométrie, sans DOM) est documentée, et le module de zone prouve qu'elle fonctionne.
- **Trois hypothèses fausses avant la bonne** sur le crash Arch : renderer DMA-BUF, puis pile graphique empaquetée (juste, mais incomplète), puis format d'empaquetage. Les quatre variables `WEBKIT_*` testées pour rien ont au moins **éliminé** une famille de causes.
